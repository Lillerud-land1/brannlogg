Widget på iPhone

Sjå kor mange dagar det er sidan siste hending, siste brann og skogbrannfaren rett på heimeskjermen eller låseskjermen. Det er gratis og krev ingen konto.

  1. Last ned den gratis appen Scriptable: App Store
  2. Trykk «Kopier koden» under.
  3. Opne Scriptable, trykk + øvst til høgre, lim inn koden og kall skriptet Brannlogg.
  4. Hald fingeren på heimeskjermen, trykk Rediger → Legg til widget og vel Scriptable og storleik.
  5. Hald fingeren på den nye widgeten, vel Rediger widget og vel Brannlogg under Script.

Lys eller mørk uansett innstilling på telefonen: skriv «lys» eller «mørk» i feltet Parameter når du redigerer widgeten. Widgeten hentar nye tal og ny kode av seg sjølv.

Vis koden
// Brannlogg Stord – widget for iPhone (Scriptable)
// Hentar den nyaste widget-koden frå bls.lillerud.com kvar gong.
// Lys eller mørk: skriv «lys» eller «mørk» i «Parameter» når du redigerer widgeten.
const KODE = 'https://bls.lillerud.com/widget-kode.js';
const fm = FileManager.local();
const fil = fm.joinPath(fm.libraryDirectory(), 'brannlogg-widget-kode.js');
try {
  const req = new Request(KODE + '?t=' + Date.now());
  req.timeoutInterval = 15;
  const kode = await req.loadString();
  if (req.response.statusCode === 200) {
    if (kode.includes('brannlogg-widget-kode')) fm.writeString(fil, kode);
  }
} catch (e) {}
if (fm.fileExists(fil)) {
  await importModule(fil).run();
} else {
  const w = new ListWidget();
  w.addText('Brannlogg: fekk ikkje henta widgeten. Sjekk nettet.');
  Script.setWidget(w);
  Script.complete();
}

      In short: Brannlogg Stord has no accounts, no cookies, no tracking and no ads. The site only counts how many people open it each day, without storing anything that could identify you.

      Who runs it

      Brannlogg Stord is a free, private website made by Leander Wågen Lillerud. It is not an official service of the police, the fire service or Stord municipality. Contact: brannloggstord@gmail.com.

      What is stored on your device

      Your settings, the time of the newest incident you have seen (for the “NEW” label), whether you have closed the privacy notice, and a copy of the site so it can open offline. This stays in your browser and is never sent to me. See Cookies.

      Technical information shared with others

      • GitHub (GitHub Pages) hosts the website. As with any website, they receive your IP address and browser information when the page loads, for operation and security.
      • Google Fonts: The fonts are loaded from Google, which then receives your IP address.

      I do not have access to this information. See the privacy policies of GitHub and Google.

      Visit numbers

      When you open the app, it sends a message to Cloudflare (Cloudflare Workers), which counts the visit. To count each device only once per day, the IP address and browser type are turned into a code together with a random number that is replaced every day. The code and the random number are deleted the same day, and the IP address is not stored. All that remains is the number of visitors per day. Nothing is stored on your device, and the information screen at the fire station is not counted. The app also sends whether it is opened on a phone, tablet or PC, and whether it is opened as an app from the home screen – this is only stored as numbers per day. If you open the app with the QR code on the information screen, it is also counted as a scan (only the number per day is stored).

      Admin access

      If someone enters a wrong admin code three times, or asks for a code to unlock it, I get a message through Cloudflare (Cloudflare Workers), GitHub and ntfy. The message says roughly where the device is (county and country) and what kind of device and browser it is. The IP address is not sent to me and is not stored. This only applies to the admin field under Settings.

      Information about incidents

      The site shows public information from Politiloggen (Norwegian Police, NLOD 2.0) and brannstatistikk.no (DSB), weather data from MET Norway and Open-Meteo, and links to news stories. Police texts and news headlines may mention places and incidents. If you think something on the site concerns you and should be corrected or removed, please get in touch.

      Phone notifications

      Notifications are sent through the ntfy app (ntfy.sh). I do not know who subscribes. See ntfy's privacy policy.

      Email

      If you email a bug report or idea, it is only used to reply to you and improve the site. Emails are stored in Gmail (Google) and deleted when the matter is closed.

      Your rights

      You can ask for access to, correction of or deletion of information about you. You can also complain to the Norwegian Data Protection Authority (datatilsynet.no).

      Changes

      This policy may change. The date at the top shows the latest change.
